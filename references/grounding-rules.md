# 锚点与中英对照规则 · Grounding rules

来源：nature-reader（`references/grounding-rules.md`、`static/core/principles.md`、`static/core/workflow.md`、`static/fragments/source/*.md`），并入本 skill 时按「精读页」而非「全文翻译」的目标做了裁剪。每条标注来源：`[reader]`、`[tutor]`、`[learning]`。

## 1. 每个解释块都要能回到原文 `[reader]`

- 规格里 `lesson`、`figure`、`table`、`bilingual`、`callout`、`diagram` 块的 `anchor` 字段是必填项，`validate_spec.py` 会检查。
- 锚点格式：短、稳定、能定位。可选形式：
  - 页码 + 段落：`p.5 ¶2`
  - 页码 + 块 ID：`p.5 S014`（按 nature-reader 的 `S001` / `C001` / `F001` / `T001` 编号）
  - 章节 + 段落：`§2.3 ¶1`、`Methods ¶4`
  - 图注 / 表格：`Figure 3 图注`、`Table 1 第 2 行`
  - 条款（合同 / 政策）：`第 4.2 条`、`Clause 7(b)`
  - 短引：`p.3「ongoing patient scenario」`（引文不超过 15 个英文词或一句中文）
- 一个块可以带多个锚点（数组）。
- 材料真的没说时，锚点写 `原文未说明`；渲染器会把它显示成醒目的缺口标记，而不是隐藏。
- 不要用整页截图代替锚点；不要用「见原文」这种无法定位的说法。

## 2. 源文件格式路由 `[reader]`

读之前先判断来源格式，并用一句话告诉用户你判断的结果，方便纠正：

| 格式 | 怎么抽取 | 锚点用什么 |
|---|---|---|
| 可选中文字的 PDF | 直接读文字层；注意双栏顺序、连字符断行、上下标 | 页码 + 段落 / 块 ID |
| 扫描 PDF | OCR 全部页面；每块记录置信度；数字、单位、基因名、公式要复核 | 页码 + 段落，低置信度标注 |
| 出版社 / 预印本 HTML | 只取正文，去掉导航、广告、相关文章；表格按标记重建 | 章节 + 段落 |
| DOI / arXiv | 先解析到实际文档，再按上一行处理；优先开放获取版本，并记录读的是哪个版本 | 同上 |
| 粘贴文本 | 以粘贴内容为准；没有页码就用顺序块 ID 或章节锚点；不臆补缺页 | 块 ID / 章节 |
| 合同、课程材料、报告 | 按条款 / 章节 / 页码 | 条款号或章节 |

不完整的来源仍然做精读页，但要在 `source_note` 和对应块里标明「未取得」「低置信度」。

## 3. 中英对照 `[reader]`

- 精读页默认中文讲解 + 关键英文术语保留，不是全文翻译。需要逐句对照时用 `bilingual` 块：`original`（原句）+ `zh`（忠实译文）+ `anchor`。
- 翻译为意义服务：保留技术术语、基因 / 蛋白名、模型名、公式、符号、引用标记、数值和单位；保留原文的限定语气（may、suggest、consistent with）。
- 不把方法细节压成模糊的概括；不把段落压成关键词列表。
- 对受版权保护的材料：`bilingual` 块只引短句（原则上不超过一句），讲解用自己的话；不整段复制。

## 4. 术语账本 `[reader]`

- 第一次接触材料时就开始建术语表：方法、模型、数据集、基因 / 蛋白、指标、单位、缩写、材料反复依赖的概念。
- 每条记录：中文、英文、在本材料中的意思（`glossary` 的 `zh` / `en` / `note`）。
- 一个概念一个名字，全页一致；缩写第一次出现时展开。
- 不发明材料没有的名字；材料里同一概念多个叫法时，选用频率最高的，并在 `note` 里列出其他叫法。

## 5. 图与表 `[reader]` `[tutor]`

- 讲图时引用图注；讲表时引用表格行；主张同时依赖文字和图时两者都引。
- 原图能否嵌入取决于许可：开放获取（如 CC BY）可嵌入并在 `caption` 标明来源与许可；受限的图不嵌入，用 `image_note` 说明原因，并可用 `diagram` 块做解释性重绘。
- 解释性重绘必须标明「解释性重绘」，不能被误认为原图；不得改动原图中的数值。
- 裁图用最紧的有效边界；不确定时标「近似裁剪」。

## 6. 回答追问时的格式 `[reader]`

```
结论：……
原文依据：p.5 ¶2–¶3；Figure 3 图注
补充说明：这是概括，不是原文逐字表述 / 原文未说明 ××
下一步：继续当前单元 | 补前置知识 | 返回原问题
```

坏的回答：没有锚点的转述；只看标题和摘要就回答需要正文的问题；说某张图支持某结论却不引图注；OCR 不确定时编造细节。
